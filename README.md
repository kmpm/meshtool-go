# MeshTools
Bunch of stuff for meshtastic written in go.

Started of as a fork of https://github.com/meshnet-gophers/meshtastic-go

One of the main use cases for me is to have an alternative to the python cli that is contained within a single executable.

__Under heavy development__.

- Uses protobuf SDK from https://github.com/meshtastic/protobufs via "github.com/kmpm/meshtastic-protobufs.go"
